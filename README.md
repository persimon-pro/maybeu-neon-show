# LOFT SHOW

Игра с шестью раундами, экраном для проектора и пультом ведущего.

## Разработка

Требуется Node.js 24 и npm.

```sh
npm ci
npm run dev
```

Откройте главную страницу сервера (порт 3000 по умолчанию). Она создаст отдельную комнату. Откройте «Главный экран», а на телефоне отсканируйте QR-код пульта. Ссылка содержит ключ ведущего; передавайте её только тем, кто должен управлять игрой. Для зрителей используйте `/display?room=...` без ключа. Ключ сохраняется в браузере создателя, удаляется из адресной строки после открытия и не отправляется в URL HTTP-запроса.

Для новой независимой комнаты нажмите «Новая игра». Разные комнаты не обмениваются состоянием. При смене комнаты нужен её ключ ведущего; одно название комнаты не даёт права управления. Телефон должен иметь доступ к серверу; в локальной сети используйте IP компьютера из QR-кода. Не публикуйте сервер разработки в интернете.

Пока соединение прервано, команды не отправляются и не накапливаются. После восстановления сервер присылает актуальное состояние. При смене раунда таймер останавливается. После отключения всех клиентов таймеры ставятся на паузу. Пустые комнаты удаляются через 24 часа. Состояние и ключи находятся в памяти сервера: после перезапуска создайте новую игру.

## Проверки

```sh
npm run lint
npm test
npm run build
npm audit
```

Тесты проверяют границы игровых данных, таймеры, сброс игры, изоляцию комнат, права ведущего, некорректные сообщения и повторное подключение.

## Production

```sh
npm ci --include=dev
npm run build
NODE_ENV=production PORT=3000 npm start
```

Express раздаёт frontend и Socket.IO на одном порту. `NODE_ENV=production` обязателен. Для публичного размещения используйте HTTPS и проксирование WebSocket. Dockerfile и render.yaml запускают Node-сервер. `npm run preview` и отдельный статический хостинг (включая прежнюю конфигурацию Vercel) не запускают сервер игры и не поддерживают совместную игру. Публичные MQTT-брокеры больше не используются. Ключ Gemini не требуется.

Для одного экземпляра достаточно одного процесса. Несколько серверных реплик требуют общего хранилища состояния и Socket.IO adapter; текущая конфигурация предназначена для одного процесса.
